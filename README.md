# 商户数据查看器

基于高德地图开放平台的 POI 商户数据采集、查看、去重、导出工具（Windows 桌面端）。

## 功能

- **全国省 / 市 / 区县三级联动**：上面选什么，表格显示什么、采集就采什么
- **12 个一级行业 + 69 个二级细分类目**：餐饮、购物、生活服务、住宿、汽车、体育休闲、医疗、科教、金融、公司企业、风景名胜、房产中介
- **实时采集显示**：采集中表格实时刷新，随时可停止，已采部分自动保存
- **电话去重**：任何两次导出之间电话零重复（自动维护去重记录）
- **Excel 导出**：支持分割导出（每份 N 条 / 分成 N 份），多文件自动编号
- **历史管理**：查看已导出电话清单、导出操作日志，可清空重建
- **绿色便携**：单文件 EXE，数据自动释放在软件旁的"数据文件"文件夹，整个文件夹拷走即用，不写系统盘

## 使用前提

需要你自己的**高德开放平台 Web 服务 API Key**（免费）：

1. 打开 [高德开放平台](https://lbs.amap.com/)，注册并实名认证
2. 控制台 → 应用管理 → 创建应用 → 添加 Key，服务平台选 **Web服务**
3. 把 Key 粘贴到软件界面的 "API Key" 输入框

免费 Key 有每日调用限额（通常够用），超出后软件会提示，第二天自动恢复。

## 运行方式

### 方式一：直接跑源码

```bash
pip install -r requirements.txt
python viewer_app.py
```

### 方式二：打包成单文件 EXE

```bash
pip install pyinstaller
# 可选：创建 key.txt 写入你的高德Key（打包后Key内嵌进EXE）
# 不创建则打包出无Key版，用户首次使用自己在界面填Key
python build_exe.py
# 产物在 dist/商户数据查看器.exe
```
